Using the Application

What the Python workflow looks like in day-to-day use, from labeling an email to sending a reviewed batch.

A normal day with the application

The workflow begins in Gmail. Useful messages are marked with the configured source label:

for_friend

No formatting or cleanup is required at this stage. The label simply identifies what should enter the next batch.

Run the export

python -m src export --format text

The application pulls the labeled messages and turns each one into its own file. After export, the working location becomes:

processed_review/

Review the generated files

The generated content is usually close to the desired result, but the workflow assumes that a person may still want to adjust formatting or remove unnecessary text. The review is intentionally quick and intentionally retained.

Send the reviewed batch

python -m src send

The reviewed files are grouped into a batch, sent, and moved out of the review workspace after successful delivery. The workspace is ready for the next run.

What changes for the user

Before

Open email → copy content → paste into document → rename file → repeat → remember what was already processed.

With the application

Label emails → export → review → send.

When something goes wrong

A failed item can be identified through the error output or logs instead of requiring the entire batch to be manually reconstructed.
