# Python Email Automation Documentation Website

Website entry point: `docs/index.html`.

The `docs/` root intentionally contains only the entry page plus organized directories:

```text
docs/
├── index.html
├── pages/
└── assets/
    ├── css/
    ├── js/
    ├── images/
    ├── examples/
    └── source/
```

The original Markdown documentation is preserved in `docs/assets/source/`.
Review example artifacts for personal or sensitive information before publishing publicly.
