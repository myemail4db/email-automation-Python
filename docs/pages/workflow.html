EMAIL AUTOMATION · PYTHON

Workflow

The complete operational path from Gmail authentication through export, human review, delivery, and archive.

Intentional boundary

The application does not run every step automatically. Export, review, and send are separate on purpose so generated content can be checked before delivery.

0

Authenticate

python -m src auth

Authenticates Gmail access and generates the local token.json used by the application.

1

Export

python -m src export --format text

The application reads messages from the configured source label and exports each selected email into the processed_review/ workspace.

At this point, the repetitive retrieval and file-generation work is complete, but nothing has been sent.

2

Review

The generated files are opened and reviewed. Formatting or extra text can be corrected before anything leaves the local review workspace.

This checkpoint is a safety feature, not an unfinished automation step.

3

Send

python -m src send

Reviewed files are grouped into a ZIP batch, sent, and then moved out of the review folder into the archive after successful delivery.
